# 实现说明

最主要的技术基线为 lilhuu/Codex-Startup-Windows，固定提交见 [references.md](references.md)。

## 启动与恢复

C# 入口 → PowerShell 发现官方 MSIX 安装及验证签名 → 官方 EXE 接收随机回环 CDP 参数 → 核对进程、同一用户、注册路径与监听归属 → 单个 Node 素材工作器 → renderer。不会修改 WindowsApps 或官方 app.asar。

默认直接启动已验证的官方 EXE，兼容官方进程没有 MSIX 包令牌的情况，但仍要求与注册包、官方签名、用户和启动进程关系匹配；非空错误包身份不会被放行。`CodexStartup.exe --msix` 可显式使用参考项目的包激活路径。已有普通官方实例只被激活，不强制关闭或接管。

恢复会移除自有 UI、样式和新文档注入脚本，释放 Blob 并停止素材工作器。调试端口随官方进程存活，完全退出后从官方入口打开可结束本次调试启动方式。

## 开屏与页面就绪

intro（可跳过）→ loading（不可跳过，至少 1500ms）→ revealing → done。可操作原生主页面或登录终点、字体、背景解码与布局连续稳定后才淡入；就绪丢失会回退 loading。没有超时强制进入未就绪主页的路径。真正的新文档重载仅创建 loading；窗口缩放和内部路由不重播开屏。

## 主题与素材

保持原生输入区与控件布局，自定义首页、设置与伙伴菜单。首页按实际高度与缩放收起整组内容；项目入口代理真实可见的原生选择器，不复制其 React 节点。深浅色跟随原生外观信号，五档思考强度对应独立场景；图片解码后交叉淡入，过渡期间保留旧 Blob。

素材桥只接受打包键，拒绝任意文件路径。初始载荷仅带代码、样式和清单，背景与视频按需加载；媒体和场景缓存有上限。结构监听过滤流式文本及自有节点；空闲主题不周期扫描 DOM。桌宠行为由媒体事件、行为定时器和走动期间的 Web Animations 驱动。

## 边界

这是非官方 Windows 社区主题。认证与网络由官方应用处理，不注入外部认证站点。隔离回归不能证明所有官方版本的 DOM、CDP、CSP、原生窗口操作或设备音频均兼容，仍需实机测试。
